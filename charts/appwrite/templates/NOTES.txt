No Ingress or HTTPRoute was created. Appwrite serves the console and the API
on one hostname, {{ $v.domain }}, and needs these routes:

  /v1/realtime  ->  service/{{ $fullname }}-realtime
  /v1           ->  service/{{ $fullname }}-api
  /             ->  service/{{ $fullname }}-{{ ternary "console" "api" .Values.console.enabled }}

Set ingress.enabled=true or httpRoute.enabled=true, or route them yourself.
A port-forward to the console alone won't work: the console sends its API
calls to its own address. To check that the API is up:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }}-api 8080:{{ .Values.api.service.port }}
  curl -H "Host: {{ $fullname }}-api" http://localhost:8080/v1/health/version
{{- end }}
